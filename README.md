# PDF翻訳ビューア

英語の論文PDFを、**見た目はそのまま・文字だけ日本語**にして表示する Chrome 拡張機能です。

![英語の論文、開いた瞬間 日本語に。](docs/01-cover.png)

![見た目そのまま、文字だけ日本語。](docs/02-before-after.png)

- 図・グラフ・数式・段組みはそのまま、本文だけが日本語に置き換わります
- 「対訳（左右）」「日本語訳のみ」「原文のみ」を切り替えて読めます
- 今の表示のまま PDF に保存できます（対訳はページ交互）
- 翻訳は Chrome に内蔵された AI が PC の中で行うので無料です（文章は外部に送られません）
- 設定で Gemini API キーを入れると、より高精度な翻訳も使えます

## 動作環境

パソコン版 Google Chrome 138 以降（スマホ版では動きません）

## インストール

1. [Releases](../../releases/latest) から `pdf-translate-viewer-*.zip` をダウンロードする
2. zip を展開（解凍）する。できたフォルダは消さずに置いておく
3. Chrome のアドレスバーに `chrome://extensions` と入力し、右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選ぶ

ローカルの PDF ファイルも開きたいときは、拡張機能の「詳細」で「ファイルの URL へのアクセスを許可する」をオンにしてください。

## 使い方

1. 論文の PDF を開く（自動でこの拡張の画面に切り替わります）
2. 右上の「ローカルAI」または「Gemini」を押す。翻訳中は実行中のボタンにローディングを表示します
3. 段落にマウスを乗せると「訳し直す」「原文を表示」ボタンが出ます

ツールバーは左にファイル名、中央に表示・倍率・PDF保存、右に翻訳言語・翻訳ボタン・設定を配置しています。通常時の案内文は表示せず、進捗やエラーはバー直下の通知で確認できます。完了の通知は数秒で消えます。

中央の「前のページ」「現在ページ / 総ページ数」「次のページ」で移動できます。現在ページに番号を入力してEnterでも移動でき、スクロールすると表示中のページ番号が更新されます。

保存アイコンから「翻訳前の原文」「翻訳後」「原文・訳文を交互」を選べます。翻訳結果がまだない場合やGeminiの訳抜けが残る場合は、原文以外を選べません。保存操作だけでGemini翻訳を開始することはありません。ローカル翻訳の未表示ページは、翻訳後のPDFを保存するときに同じローカルAIで翻訳します。

保存アイコンの隣の引用ボタンから、MLA・APA・ISO 690の引用文を表示・コピーできます。BibTeX、EndNote・RefMan・RefWorksで取り込めるRIS形式も表示・コピー・保存できます。PDFのURL・メタデータ・先頭ページに明示されたDOI／arXiv IDを読み取り、公開書誌情報から引用を取得します。arXiv論文の出版版は、タイトルと先頭著者が一致する候補が1件だけの場合に使用し、それ以外はarXiv版を使います。取得元とDOIをパネルに表示し、識別子を手動で変更することもできます。

引用パネルと設定画面は外側のクリックでも閉じます。BibTeXはフィールドごとに改行し、値や著者名内のカンマを保ったまま表示・コピー・保存します。「Google Scholarで確認」は対象タイトルの検索結果を別タブで開きます。Scholar側のBibTeXを使う場合は、検索結果の「引用」から選んでください。

引用ボタンを押すまで書誌情報サービスには接続しません。外部へ送るのは識別子と、出版版の照合に使う公開済みのarXivタイトルだけです。PDF本文・Cookie・Gemini APIキーは送らず、Geminiのquotaも使いません。取得済みの書式は同じタブ内で再利用します。Google Scholarの非公開APIや拡張コードのコピーは使用していないため、Scholarとは引用スタイルの版や書誌データの差が出る場合があります。

倍率調節の隣の「幅に合わせる」「高さに合わせる」アイコンで、タブの表示領域に合わせられます。幅合わせは対訳なら左右2ページ、片側表示なら1ページが基準です。高さ合わせは現在読んでいるページを、ツールバーを除いた高さに合わせます。フィット中はタブサイズや表示方法の変更に追従し、「＋」「−」「100%」で手動倍率に戻ります。倍率の変更による翻訳APIの呼び出しはありません。

Cmd/Ctrl＋「＋」「−」「0」やピンチ／Ctrl＋ホイールでも、ヘッダーを拡大せずPDF部分だけの倍率を変更します。ビューアのタブではChrome自身のズームを無効にし、PDF倍率をChromeへ同期しないため、PDFを拡大してもChrome側の倍率やズームポップオーバーは動きません。Chromeのメニューからの倍率変更もこのタブでは無効になり、別ページへの移動で通常のズームに戻ります。

### 翻訳がいらないときは（ON / OFF）

ツールバーのアイコンを押すと、小さな設定パネルが開きます。

- **「PDFを自動で翻訳ビューアで開く」をOFF** にすると、PDF はいつものビューア（Chrome 標準や Google Scholar PDF Reader など）で開きます。OFF のときはアイコンに「OFF」と表示されます
- OFF のままでも、パネルの「このPDFを翻訳ビューアで開く」で、そのPDFだけ翻訳ビューアで開けます
- 翻訳ビューアで開いたあとに翻訳がいらなくなったら、ファイル名の横の「通常のPDFビューアで開く」アイコンで切り替えられます

## Gemini モードについて

右上の設定アイコンから [Google AI Studio](https://aistudio.google.com/apikey) で取得したAPIキーを保存し、「Gemini」を押すと使えます。「ローカルAI」はAPIキー不要で、文章を外部へ送信しません。設定の保存だけでは翻訳を開始しません。

既定モデルは `gemini-3.5-flash-lite` です。すでにモデルを保存している場合は、その選択を維持します。切り替えるには「⚙ 設定」のモデル欄で `gemini-3.5-flash-lite` または `gemini-3.8-flash` を選んで保存してください。

Gemini モードでは、全ページから抽出したテキストをまとめて送り、通常は **1つのPDFを1回のリクエストで一括翻訳**します。図表などの翻訳対象外のテキストも、抽出できたものは文脈として渡します。PDFファイル自体やページ画像は送りません。Chrome 内蔵モードは段落ごとの翻訳です。

訳文は段落IDで元の位置に戻します。スクロールやPDF保存では、その画面で取得済みの翻訳を再利用するため追加の翻訳リクエストは発生しません。画面を開き直して翻訳する、翻訳ボタンを再度押す、言語を変更する場合は新たに翻訳します。モデルの変更は次回の「Gemini」ボタンからの翻訳に適用します。「訳し直す」は全文を文脈として添え、その段落だけを再翻訳します。

APIには `{"translations": [{"id": 1, "text": "訳文"}, ...]}` という固定形式を指定します。翻訳対象の原文に文書全体での連番 `translate_id` を添え、参照用のブロックには番号を付けません。全ページのテキストはそのまま文脈として渡します。出力スキーマにはIDの列挙・位置ごとの制約・件数制約を含めず、文書サイズによらず同じ小さい形式を使います。受信後、番号の範囲・網羅性・重複・空の訳文・形式不正・途中切れを検証し、番号から元の段落IDへ戻します。応答順が変わっても段落は対応しますが、番号の推測や補完は行いません。問題があれば翻訳完了とせず、不足・空欄などの件数を表示します。長いPDFがモデルの入出力上限に収まらない場合も、自動で分割・再送しません。レート制限や一時的なサーバーエラーでは、待って最大6回再試行することがあります。

訳抜けだけの場合は、受信済みの訳文をそのタブのメモリに保持し、「不足N段落だけ再翻訳」ボタンを表示します。このボタンを押したときだけ、全文を文脈として添え、不足段落をまとめて追加リクエストで翻訳します。補完が終わるまでは全文の表示・翻訳済みPDFの保存を完了扱いにしません。途中切れ・重複・対象外の番号などが混ざる場合は、この補完を行いません。タブの更新や全文の翻訳やり直しでは保持した訳文が失われます。

Gemini API の無料枠では、送った文章が Google のサービス改善に使われることがあります。未公開の論文などには、無料の内蔵モードを使ってください。

### 開発時の確認

`node --test tests/*.test.mjs` で、全文の一括送信・段落の対応・応答不正時の停止・結果の共有・キャンセルをモックAPIで確認できます。実際のAPIキーや無料枠は使いません。
